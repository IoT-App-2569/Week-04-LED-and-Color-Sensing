#### 4.2 จากการสังเกตุ LED 
ช่วงที่ 1 (Phase R): หลอด LED สีแดง สว่างขึ้นเป็นเวลา 2.5 วินาที แล้วดับลง

ช่วงที่ 2 (Phase G): หลอด LED สีเขียว สว่างขึ้นต่อทันทีเป็นเวลา 2.5 วินาที แล้วดับลง

ช่วงที่ 3 (Phase B): หลอด LED สีน้ำเงิน สว่างขึ้นต่อเป็นเวลา 2.5 วินาที แล้วดับลง

ช่วงที่ 4 (Rest Phase): หลอด LED ดับเป็นเวลา 3 วินาที เพื่อรอให้ประจุไฟฟ้าคงค้าง คายออกจนหมด ก่อนจะวนกลับมาเริ่มต้นแสดงแสงสีแดงใหม่อีกครั้งตามรอบวงลูป

2. **คำถามนำเพื่อการวิเคราะห์เชิงระบบ (Critical Thinking):**
    
    - จากกราฟที่พล๊อตออกมา นักศึกษาสังเกตเห็นแนวโน้มตัวเลขของค่า ADC ตั้งแต่แซมเปิ้ลที่ 1 ไต่ระดับลงมาหรือขึ้นไปจนถึงแซมเปิ้ลที่ 20 อย่างไร? 

    ```
    ค่า ADC จะมีลักษณะ ลดลงอย่างรวดเร็ว จากแซมเปิ้ลแรกๆ เนื่องจากยังมีประจุไฟฟ้าคงค้างและแรงดันไฟฟ้าตกคร่อมจากแสงและรอยต่อ PN อยู่มากหลังปิดไฟ) จากนั้นกราฟจะค่อยๆ ลดลงและลู่เข้าสู่ค่าคงที่ (Steady State) ที่ระดับสัญญาณพื้นหลัง (Noise Floor) ในช่วงท้ายๆ ของแซมเปิ้ล

    ```
    - สัญญาณไฟฟ้าเข้าสู่ความนิ่ง (Settling) ที่แซมเปิ้ลใด หรือใช้เวลากี่มิลลิวินาที?

    ```
    กราฟจะเริ่มเข้าสู่ความนิ่ง และคงที่อยู่ที่ประมาณ แซมเปิ้ลที่ 11 ถึง 13 ซึ่งคำนวณเป็นเวลาได้ประมาณ 11 x 150 ms = 1,650 ms ถึง 1,950 ms (1.65 - 1.95 วินาที) หลังจากเริ่มเข้าสู่ช่วงพักรอบ 

    ```
        
    - ความลาดเอียงของเส้นกราฟที่เกิดขึ้นในช่วงแรกของการสลับสถานะไฟนี้ เป็นหลักฐานเชิงประจักษ์สะท้อนข้อจำกัดคุณสมบัติทางกายภาพใดของรอยต่อ PN บน LED ภาครับ และโครงสร้างตัวเก็บประจุสุ่มสัญญาณภายในไมโครคอนโทรลเลอร์?

    ```
    รอยต่อ PN บน LED ภาครับ มีคุณสมบัติเทียบเท่ากับตัวเก็บประจุแสง ซึ่งเมื่อได้รับแสงกระตุ้นจะสะสมประจุ และเมื่อตัดแสงจะเกิดการคายประจุ ออกมาช้าๆ ตามค่าอิมพีแดนซ์สูงของวงจร

    โครงสร้างภายใน ADC (Sample-and-Hold Circuit) ภายในไมโครคอนโทรลเลอร์จะมีตัวเก็บประจุสำหรับเก็บประจุชั่วขณะเพื่อแปลงสัญญาณอนาล็อกเป็นดิจิทัล (Sampling Capacitor) ซึ่งต้องใช้เวลาในการประจุ/คายประจุร่วมกับแหล่งสัญญาณภายนอก ทำให้เกิดพฤติกรรม Transient State ในช่วงเปลี่ยนผ่านสถานะ

    ```
        
    - หากในใบงานถัดไปเราต้องการ "หาค่าเฉลี่ยของระดับแรงดันสะท้อนที่แท้จริง" โดยไม่ให้เฟสสัญญาณที่กำลังเปลี่ยนแปลง (Transient State) นี้ไปดึงค่าสถิติให้เพี้ยน นักศึกษาคิดว่าเราควรเลือกแซมเปิ้ลช่วงใดมาคำนวณ หรือควรเขียนโปรแกรมหน่วงเวลาหลบเลี่ยงอาการ Settling 

    ```
    การเลือกช่วงแซมเปิ้ล ควรเลือกตัดข้อมูลในช่วงแรกทิ้ง (เช่น ตัดแซมเปิ้ลที่ 1 ถึง 10 ออก) และนำเฉพาะข้อมูลในช่วงที่สัญญาณนิ่งแล้วตั้งแต่ แซมเปิ้ลที่ 11 ถึง 20 มาคำนวณหาค่าเฉลี่ย

    การเขียนโปรแกรมหน่วงเวลา (Delay/Settling Time Skip): ควรเพิ่มคำสั่งหน่วงเวลา (เช่น vTaskDelay หรือ delay) รอให้ผ่านพ้นช่วงการคายประจุ (Transient Phase) ไปก่อนสักประมาณ 1.5 - 2 วินาทีแรก หลังจากสั่งเปลี่ยนสถานะหลอดไฟ ก่อนที่ระบบจะเริ่มกระบวนการสุ่มเก็บข้อมูลจริง เพื่อให้ได้ค่าที่เสถียรและแม่นยำที่สุด

    ```

2. **คำถามเชิงวิเคราะห์ (Engineering Evaluation):**
    
    - หลังจากเปลี่ยนสถาปัตยกรรมซอฟต์แวร์มาใช้ระบบกรองบิตดิบแบบ `Trimmed Mean` ก่อนทำการแปลงแรงดัน เปรียบเทียบกับพฤติกรรมอนุกรมเวลาในใบงานที่ 2 แล้ว ค่าความผันผวน ($SD$) มีการพัฒนาไปในทางที่ดีขึ้นอย่างไร?

    ```
    การใช้อัลกอริทึม Trimmed Mean (ตัดข้อมูลขอบบนและขอบล่างออกฝั่งละ 10%) ช่วยกำจัดค่าผิดปกติ (Outliers) เช่น สัญญาณรบกวนฉับพลัน (Noise Spikes) ออกไปก่อนนำไปคำนวณทางสถิติ ส่งผลให้ค่าส่วนเบี่ยงเบนมาตรฐาน (SD) ลดลงอย่างเห็นได้ชัด ทำให้ข้อมูลมีความนิ่ง เสถียร และมีความพร้อมในการนำไปแปลงหน่วยเป็นแรงดันไฟฟ้าทางกายภาพมากกว่าการใช้ค่าดิบแบบเดิม

    ```
        
    - ในการนำข้อมูลดิจิทัลนี้ไปใช้ควบคุมหุ่นยนต์แยกแยะวัตถุสีในโลกจริง เหตุใดการระบุหน่วยวัดร่วมประมวลผลในรูปของ **แรงดันทางกายภาพ (mV)** จึงมีความสำคัญและเสถียรมากกว่าการใช้ข้อมูลระดับบิตดิจิทัลดิบ (Raw Scale 0-4095) ตรง ๆ? ให้แปรผลโดยอิงความรู้จากเนื้อหาในหัวข้อตำราเรียนเรื่อง "สองโลกที่แตกต่าง"

    ```
    เนื่องจากข้อมูลระดับบิตดิบ (Raw Scale 0-4095) เป็นเพียงตัวเลขเชิงนามธรรมที่ขึ้นอยู่กับคุณสมบัติเฉพาะตัวของ ADC บนฮาร์ดแวร์แต่ละบอร์ด (เช่น ความเพี้ยนจากแรงดันอ้างอิง หรือความคลาดเคลื่อนของอุปกรณ์) ซึ่งอยู่ในโลกดิจิทัลที่ไม่สะท้อนความเป็นจริงทางกายภาพ ในทางกลับกัน การแปลงข้อมูลให้อยู่ในรูปของ หน่วยแรงดันทางกายภาพ (mV) ผ่านกระบวนการ Calibration จะช่วยสร้างภาษากลางที่เป็นสากล ทำให้เมื่อนำโค้ดหรือโมเดลไปรันบนฮาร์ดแวร์บอร์ดอื่นๆ ค่าขีด (Threshold) สำหรับแยกแยะสีของหุ่นยนต์จะไม่เพี้ยนตามความแตกต่างของบอร์ด ช่วยให้ระบบมีความยืดหยุ่น แม่นยำ และเชื่อถือได้ในโลกแห่งความจริงครับ

    ```
