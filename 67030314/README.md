#### วิเคราะห์ผล
- ค่า ADC ลดลงแบบเอกซ์โพเนนเชียล ลดเร็วในช่วงแรกแล้วแบนราบ (R: 370 → ~10, G: 1311 → ~20, B: 614 → ~13)
- สัญญาณนิ่งที่แซมเปิ้ลที่ 7–8 หรือประมาณ 900–1,050 ms หลังดับไฟ
- เกิดจากความจุไฟฟ้าแฝงของรอยต่อ PN ที่อิมพีแดนซ์สูง ร่วมกับตัวเก็บประจุ Sample-and-Hold ของ ADC (วงจร RC, τ ≈ 200 ms)
- ควรใช้เฉพาะแซมเปิ้ลที่ 9–20 หรือหน่วงเวลาอย่างน้อย ~1,200 ms ก่อนเริ่มอ่าน

#### ตารางคัดกรองข้อมูล (SD 2.00–35.00 และไม่มีค่า 0.00)

| รอบที่ | R mean / sd (mV) | G mean / sd (mV) | B mean / sd (mV) | ผลคัดกรอง |
| :---: | :---: | :---: | :---: | :--- |

| 3 | 0.00 / 0.00 | 1084.00 / 18.00 | 471.00 / 22.00 | ไม่ผ่าน (R = 0.00) |
| 4 | 327.00 / 12.00 | 1139.00 / 41.00 | 512.00 / 14.00 | ไม่ผ่าน (SD ของ G = 41.00) |
| 5 | 322.00 / 8.00 | 1151.00 / 9.00 | 506.00 / 12.00 | ✅ ผ่าน |

ชุดข้อมูลที่น่าเชื่อถือ: **รอบที่ 1, 2 และ 5**

#### วิเคราะห์ผล
- เมื่อใช้ Trimmed Mean ค่า SD เหลือเพียง 8–15 mV จากเดิมในใบงานที่ 2 ที่ค่าดิบแกว่งตั้งแต่หลักร้อยถึงหลักพัน
- หน่วย mV เป็นค่าในโลกกายภาพที่ผ่านการปรับเทียบแล้ว จึงใช้เกณฑ์ตัดสินสีเดียวกันได้กับทุกบอร์ดและทุกการตั้งค่า ส่วนค่า Raw ความหมายเปลี่ยนไปตาม Attenuation, Bitwidth และชิปแต่ละตัว
- หมายเหตุ: ESP32-C6 ไม่มี Line Fitting โค้ดจึงแปลงหน่วยด้วยสูตร `raw × 3300 / 4095`
