    - สัญญาณไฟฟ้าเข้าสู่ความนิ่ง (Settling) ที่แซมเปิ้ลใด หรือใช้เวลากี่มิลลิวินาที?

    ตอบ :   สัญญาณไฟฟ้าเข้าสู่ความนิ่งที่แซมเปิ้ล 14

    - ความลาดเอียงของเส้นกราฟที่เกิดขึ้นในช่วงแรกของการสลับสถานะไฟนี้ เป็นหลักฐานเชิงประจักษ์สะท้อนข้อจำกัดคุณสมบัติทางกายภาพใดของรอยต่อ PN บน LED ภาครับ และโครงสร้างตัวเก็บประจุสุ่มสัญญาณภายในไมโครคอนโทรลเลอร์?

     - การคาย ชาร์จประจุไฟฟ้าสะสม เมื่อต่อ LED ภาครับเข้ากับขา ADC ของ MCU จะเกิดค่าคงที่เวลา
 		2. ข้อจำกัดทางโครงสร้างตัวเก็บประจุสุ่มสัญญาณภายในไมโครคอนโทรลเลอร์ (ADC Module)
     - ความลาดเอียงและค่าที่กระโดดไปมาในช่วงแรกสุดของการสลับสถานะ คือผลกระทบจากช่วงเวลาการปรับตัวทางไฟฟ้าชั่วขณะก่อนที่ตัวเก็บประจุสุ่มสัญญาณภายในของ ADC จะเก็บประจุและปรับระดับแรงดันจนเสถียร สอดคล้องกับคุณสมบัติย่านการตอบสนองเชิงเส้นของฮาร์ดแวร์
   ```
       
    - หากในใบงานถัดไปเราต้องการ "หาค่าเฉลี่ยของระดับแรงดันสะท้อนที่แท้จริง" โดยไม่ให้เฟสสัญญาณที่กำลังเปลี่ยนแปลง (Transient State) นี้ไปดึงค่าสถิติให้เพี้ยน นักศึกษาคิดว่าเราควรเลือกแซมเปิ้ลช่วงใดมาคำนวณ หรือควรเขียนโปรแกรมหน่วงเวลาหลบเลี่ยงอาการ Settling นี้อย่างไร?
   ```
   ตอบ : ควรตัดข้อมูลช่วง 1–10 แซมเปิ้ลแรกทิ้ง เนื่องจากเป็นช่วงที่แรงดันกำลังคายชาร์จประจุอย่างรวดเร็ว
   เลือกเฉพาะช่วงสภาวะคงตัวที่แซมเปิ้ล 12–20 มาเข้าสูตรคำนวณสถิติช่วงเวลานี้แรงดันจะเริ่มราบเรียบ ตกกระทบช้าลงจนเกือบเป็นเส้นตรงและสะท้อนระดับความเข้มแสงจริง

# ผลลัพธ์ Lab03
### ใบงานปฏิบัติการ สัปดาห์ที่ 4 การทดลองย่อยที่  3
### หัวข้อ: การประมวลผลสัญญาณเชิงสถิติและการแปลงข้อมูลสู่โลกดิจิทัล (Robust Statistical Filtering)

1. **การคัดกรองข้อมูลคุณภาพ (Data Selection Report):**
    
    ให้นักศึกษาสังเกตค่าสถิติที่แสดงผลบนหน้าจอต่อเนื่องกัน 5 รอบวงลูป ให้นักศึกษาทำเครื่องหมายคัดเลือกเฉพาะชุดข้อมูลที่ผ่านเกณฑ์คุณภาพวิศวกรรมลงในตาราง โดยมีข้อกำหนดว่า **"ชุดข้อมูลที่น่าเชื่อถือ จะต้องมีค่า SD ต่ำสอดคล้องกันทุกเฟสสี (เช่น อยู่ในช่วง 2.00 ถึง 35.00) และต้องไม่มีค่าเฉลี่ยหรือค่า SD ใดหลุดเป็น 0.00 ในขณะที่มีการส่องสว่างส่งแสงข้ามช่องสัญญาณ"**

3. **คำถามเชิงวิเคราะห์ (Engineering Evaluation):**
    
    - หลังจากเปลี่ยนสถาปัตยกรรมซอฟต์แวร์มาใช้ระบบกรองบิตดิบแบบ `Trimmed Mean` ก่อนทำการแปลงแรงดัน เปรียบเทียบกับพฤติกรรมอนุกรมเวลาในใบงานที่ 2 แล้ว ค่าความผันผวน ($SD$) มีการพัฒนาไปในทางที่ดีขึ้นอย่างไร?
      ```
      ตอบ :
      ก่อนปรับปรุง: ค่า SD พุ่งสูง เนื่องจากสุ่มอ่านข้อมูลในช่วงที่แรงดันคายประจุและลดลงอย่างรวดเร็ว ทำให้ค่าที่ได้ผันผวนและคลาดเคลื่อนจากความเป็นจริง
      หลังปรับปรุง: ค่า SD ลดลง (เหลือเพียง 2.33 - 46.90) สะท้อนถึงการพัฒนา 2 ด้านหลัก
      1. กำจัดนอยส์และค่าผิดปกติได้หมดจด: การรอให้พ้นช่วงผันผวน (Transient) ร่วมกับการตัดข้อมูลขอบบน-ล่าง ช่วยกรองแรงดันตกค้าง สไปค์ (Spike) แสงรบกวน และไฟบ้าน 50 Hz ออกไปได้สำเร็จ
      2. สัญญาณมีความเสถียรและน่าเชื่อถือสูง: ข้อมูลที่ผ่านการกรองมีการเกาะกลุ่มกันแน่น เปลี่ยนจากสัญญาณอนุกรมเวลาที่ผันผวนให้กลายเป็นค่าที่คงที่และแม่นยำ
      ```
        
    - ในการนำข้อมูลดิจิทัลนี้ไปใช้ควบคุมหุ่นยนต์แยกแยะวัตถุสีในโลกจริง เหตุใดการระบุหน่วยวัดร่วมประมวลผลในรูปของ **แรงดันทางกายภาพ (mV)** จึงมีความสำคัญและเสถียรมากกว่าการใช้ข้อมูลระดับบิตดิจิทัลดิบ (Raw Scale 0-4095) ตรง ๆ? ให้แปรผลโดยอิงความรู้จากเนื้อหาในหัวข้อตำราเรียนเรื่อง "สองโลกที่แตกต่าง"
      ```
      ตอบ :
      -	เนื่องจากแสงสะท้อนสร้างแรงดันตกคร่อมรอยต่อ PN จาก Photovoltaic Effect การใช้หน่วย mV จึงเป็นการอ้างอิงระดับพลังงานแสงในโลกจริงโดยตรง
	  -	แก้ปัญหา ADC ไม่เป็นเชิงเส้น เพราะตัวแปลง ADC มีจุดอิ่มตัวและขอบสัญญาณที่ไม่เป็นเส้นตรง การแปลง Raw Bit ผ่าน Calibration มาเป็น mV ช่วยชดเชยความเพี้ยนของฮาร์ดแวร์ให้ได้ค่าสัญญาณไฟตรงที่แม่นยำ
	  -	ช่วยให้สร้างค่าบ่งบอกสีของวัตถุชิ้นนั้นได้อย่างแม่นยำ เพื่อตั้งค่าขีดเริ่มเปลี่ยนในการแยกแยะสีของหุ่นยนต์ได้อย่างถูกต้อง สม่ำเสมอ และไม่แกว่งตามนอยส์ไฟฟ้า
      ```
