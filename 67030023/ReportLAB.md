4.2 คำถามนำเพื่อการวิเคราะห์เชิงระบบ (Critical Thinking)

```
1. จากกราฟที่พล๊อตออกมา นักศึกษาสังเกตเห็นแนวโน้มตัวเลขของค่า ADC ตั้งแต่แซมเปิ้ลที่ 1 ไต่ระดับลงมาหรือขึ้นไปจนถึงแซมเปิ้ลที่ 20 อย่างไร?
ตอบ: แนวโน้มสัญญาณ ADC: กราฟทั้งสามสี (R G B) แสดงรูปคลื่นสามเหลี่ยมซ้ำ ๆ โดยค่า ADC เพิ่มจาก 0 ไปถึงค่าสูงสุด ≈ 2500–2800 แล้วลดกลับลง 0 เป็นคาบต่อเนื่อง
ลักษณะนี้บ่งบอกว่าเซนเซอร์รับแสงและวงจร ADC ตอบสนองต่อการสลับสถานะไฟแบบคาบเวลา (periodic excitation) ซึ่งไม่มีแนวโน้มเพิ่มหรือลดถาวร แต่คงรูปแบบซ้ำตามรอบการวัด
```
```
2. สัญญาณไฟฟ้าเข้าสู่ความนิ่ง (Settling) ที่แซมเปิ้ลใด หรือใช้เวลากี่มิลลิวินาที?
ตอบ:  การเข้าสู่ความนิ่งของสัญญาณ: จากรูปคลื่นที่ซ้ำกันทุกคาบ สัญญาณจะเข้าสู่สภาวะนิ่งหลังผ่านไป 1–2 รอบแรกของการสลับสถานะ
หากแต่ละแซมเปิ้ลใช้เวลาประมาณ 10 ms (ตามการอ่าน Serial Monitor) ระบบจะเข้าสู่ความนิ่งภายใน ≈ 20 ms หลังเริ่มการวัด
```
```
3. ความลาดเอียงของเส้นกราฟที่เกิดขึ้นในช่วงแรกของการสลับสถานะไฟนี้ เป็นหลักฐานเชิงประจักษ์สะท้อนข้อจำกัดคุณสมบัติทางกายภาพใดของรอยต่อ PN บน LED ภาครับ และโครงสร้างตัวเก็บประจุสุ่มสัญญาณภายในไมโครคอนโทรลเลอร์?
ตอบ: ข้อจำกัดของรอยต่อ PN ใน LED: ความลาดเอียงช่วงต้นสะท้อนการหน่วงของกระแสไฟในรอยต่อ PN ของ LED ภาครับ ซึ่งต้องใช้เวลาในการสะสมและคายประจุ
ตัวเก็บประจุสุ่มสัญญาณในไมโครคอนโทรลเลอร์ ก็มีส่วนทำให้เกิด Transient เพราะต้องชาร์จและดิสชาร์จระหว่างการสลับสถานะ จึงเห็นกราฟไม่ขึ้นลงทันทีแต่มีความลาดเอียง
```
```
4. หากในใบงานถัดไปเราต้องการ "หาค่าเฉลี่ยของระดับแรงดันสะท้อนที่แท้จริง" โดยไม่ให้เฟสสัญญาณที่กำลังเปลี่ยนแปลง (Transient State) นี้ไปดึงค่าสถิติให้เพี้ยน นักศึกษาคิดว่าเราควรเลือกแซมเปิ้ลช่วงใดมาคำนวณ หรือควรเขียนโปรแกรมหน่วงเวลาหลบเลี่ยงอาการ Settling นี้อย่างไร?
ตอบ: เพื่อหลีกเลี่ยงผลกระทบจากเฟส Transient ควรเลือกแซมเปิ้ล หลังระบบนิ่งแล้ว เช่น แซมเปิ้ล 5–20
หรือเขียนโปรแกรมให้ หน่วงเวลา (Delay) ประมาณ 20–30 ms หลังการสลับสถานะไฟก่อนเริ่มอ่านค่า ADC เพื่อให้ได้ค่าที่แท้จริงของแรงดันสะท้อน
```

1. **การคัดกรองข้อมูลคุณภาพ (Data Selection Report):**
    
    ให้นักศึกษาสังเกตค่าสถิติที่แสดงผลบนหน้าจอต่อเนื่องกัน 5 รอบวงลูป ให้นักศึกษาทำเครื่องหมายคัดเลือกเฉพาะชุดข้อมูลที่ผ่านเกณฑ์คุณภาพวิศวกรรมลงในตาราง โดยมีข้อกำหนดว่า **"ชุดข้อมูลที่น่าเชื่อถือ จะต้องมีค่า SD ต่ำสอดคล้องกันทุกเฟสสี (เช่น อยู่ในช่วง 2.00 ถึง 35.00) และต้องไม่มีค่าเฉลี่ยหรือค่า SD ใดหลุดเป็น 0.00 ในขณะที่มีการส่องสว่างส่งแสงข้ามช่องสัญญาณ"**
    
3. **คำถามเชิงวิเคราะห์ (Engineering Evaluation):**
    
    - หลังจากเปลี่ยนสถาปัตยกรรมซอฟต์แวร์มาใช้ระบบกรองบิตดิบแบบ `Trimmed Mean` ก่อนทำการแปลงแรงดัน เปรียบเทียบกับพฤติกรรมอนุกรมเวลาในใบงานที่ 2 แล้ว ค่าความผันผวน ($SD$) มีการพัฒนาไปในทางที่ดีขึ้นอย่างไร?
      ตอบ Trimmed Mean จะตัดค่าผิดปกติ (outlier) ออกก่อนเฉลี่ย ทำให้ข้อมูลไม่ถูกดึงไปโดยค่าที่เบี่ยงเบนมาก เมื่อเปรียบเทียบกับพฤติกรรมอนุกรมเวลาในใบงานที่ 2 พบว่า ค่าความผันผวน (SD) ลดลงอย่างชัดเจน และมีความสอดคล้องกันทุกเฟสสี (R, G, B)
ผลคือข้อมูลมีความเสถียรและน่าเชื่อถือมากขึ้น เหมาะสำหรับการนำไปใช้ในงานควบคุมจริง เช่น การตรวจจับสีของวัตถุ
        
    - ในการนำข้อมูลดิจิทัลนี้ไปใช้ควบคุมหุ่นยนต์แยกแยะวัตถุสีในโลกจริง เหตุใดการระบุหน่วยวัดร่วมประมวลผลในรูปของ **แรงดันทางกายภาพ (mV)** จึงมีความสำคัญและเสถียรมากกว่าการใช้ข้อมูลระดับบิตดิจิทัลดิบ (Raw Scale 0-4095) ตรง ๆ? ให้แปรผลโดยอิงความรู้จากเนื้อหาในหัวข้อตำราเรียนเรื่อง "สองโลกที่แตกต่าง"
      ตอบ หากใช้ข้อมูลดิบจาก ADC (0–4095) ตรง ๆ จะเป็นเพียงตัวเลขดิจิทัลที่ไม่สะท้อนความหมายทางฟิสิกส์ การแปลงเป็น แรงดันทางกายภาพ (mV) ทำให้ข้อมูลมีความหมายเชิงวิศวกรรม สามารถเปรียบเทียบกับมาตรฐานอุปกรณ์อื่น ๆ ได้
ในการควบคุมหุ่นยนต์แยกแยะวัตถุสี การใช้หน่วยแรงดันช่วยให้ระบบ เสถียรและแม่นยำกว่า เพราะแรงดันสัมพันธ์กับพลังงานจริงของสัญญาณ ไม่ใช่เพียงตัวเลขสเกลนี่คือสิ่งที่ตำราเรียกว่า “สองโลกที่แตกต่าง”: โลกดิจิทัล (Raw Scale) กับโลกฟิสิกส์ (Voltage) ซึ่งการเชื่อมโยงสองโลกนี้ทำให้การประมวลผลมีความหมายและใช้งานได้จริง
