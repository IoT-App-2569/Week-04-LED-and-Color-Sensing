##### 4.2 คำถามนำเพื่อการวิเคราะห์เชิงระบบ (Critical Thinking)

###### 1. จากกราฟที่พล๊อตออกมา นักศึกษาสังเกตเห็นแนวโน้มตัวเลขของค่า ADC ตั้งแต่แซมเปิ้ลที่ 1 ไต่ระดับลงมาหรือขึ้นไปจนถึงแซมเปิ้ลที่ 20 อย่างไร?
**ตอบ**: 
```
Red, Green และ Blue ADC Raw: ทั้ง 3 สีแสดงแนวโน้มเหมือนกัน คือ ไม่มีช่วงไต่ระดับ (No Transient/Decay Slope) แต่กราฟแกว่งสลับไปมาแบบฟันปลา (Sawtooth Pattern) ระหว่างค่า 0 กับระดับสูงสุด (ประมาณ 2400-2600) ทันทีอย่างสม่ำเสมอตั้งแต่แซมเปิ้ลที่ 1 ถึง 20 สลับกันไปแบบไม่มีช่วงหน่วง
```
###### 2. สัญญาณไฟฟ้าเข้าสู่ความนิ่ง (Settling) ที่แซมเปิ้ลใด หรือใช้เวลากี่มิลลิวินาที?
**ตอบ**: 
```
- สัญญาณเข้าสู่สภาวะคงที่ (Settling State) ทันทีตั้งแต่ แซมเปิ้ลที่ 2 (กระโดดจาก 0 ไปแตะยอดสูงสุดทันที)
- การคำนวณเวลา (Settling Time): เนื่องจากกราฟไม่มีช่วงไต่ระดับให้เห็น แสดงว่าวงจรคายประจุและปรับตัวเข้าสู่ความนิ่งได้ เร็วกว่า ระยะเวลาหน่วงสุ่มอ่าน (Sampling Delay) มากๆ (Settling Time < ระยะเวลาสุ่มอ่านในโค้ด) ระบบจึงจับภาพช่วง Transient ไม่ทัน
```

###### 3. ความลาดเอียงของเส้นกราฟที่เกิดขึ้นในช่วงแรกของการสลับสถานะไฟนี้ เป็นหลักฐานเชิงประจักษ์สะท้อนข้อจำกัดคุณสมบัติทางกายภาพใดของรอยต่อ PN บน LED ภาครับ และโครงสร้างตัวเก็บประจุสุ่มสัญญาณภายในไมโครคอนโทรลเลอร์?
**ตอบ**: 
```
ความลาดเอียง (ถึงแม้กราฟเราจะชันมากจนเกือบตั้งฉาก) สะท้อนข้อจำกัด 2 ส่วนคือ:
1.LED ภาครับ: มีความจุไฟฟ้าแฝง (Parasitic Capacitance) ที่รอยต่อ PN
2.ADC ภายในไมโครคอนโทรลเลอร์: มีวงจร Sample and Hold ที่ต้องใช้เวลาในการชาร์จและคายประจุ (Charge/Discharge) เข้าตัวเก็บประจุ ทำให้ในทางฟิสิกส์ แรงดันไฟฟ้าไม่สามารถกระโดดเปลี่ยนสถานะแบบขอบเหลี่ยม (ตั้งฉาก) ได้ในพริบตาเดียว
```

###### 4. หากในใบงานถัดไปเราต้องการ "หาค่าเฉลี่ยของระดับแรงดันสะท้อนที่แท้จริง" โดยไม่ให้เฟสสัญญาณที่กำลังเปลี่ยนแปลง (Transient State) นี้ไปดึงค่าสถิติให้เพี้ยน นักศึกษาคิดว่าเราควรเลือกแซมเปิ้ลช่วงใดมาคำนวณ หรือควรเขียนโปรแกรมหน่วงเวลาหลบเลี่ยงอาการ Settling นี้อย่างไร?
**ตอบ**: 
```
- การเขียนโปรแกรม: ควรใส่คำสั่ง Delay (เช่น 10-50 ms) ทิ้งไว้ทันทีหลังจากสั่งเปิด/ปิดไฟ LED ภาคส่ง เพื่อให้เวลาตัวเก็บประจุในวงจรทำงานจนเสร็จ แล้วค่อยใช้คำสั่งอ่านค่า ADC    
- การเลือกแซมเปิ้ล: ตัดข้อมูลช่วงแรกๆ ทิ้ง (เช่น ข้าม 3-5 แซมเปิ้ลแรกไปเลย) แล้วนำเฉพาะค่าแซมเปิ้ลช่วงท้ายๆ ที่คงที่แล้วมาหาค่าเฉลี่ย จะได้ค่าที่ไม่เพี้ยน
```

### หัวข้อ: การประมวลผลสัญญาณเชิงสถิติและการแปลงข้อมูลสู่โลกดิจิทัล (Robust Statistical Filtering)

1. **การคัดกรองข้อมูลคุณภาพ (Data Selection Report):**
    
    ให้นักศึกษาสังเกตค่าสถิติที่แสดงผลบนหน้าจอต่อเนื่องกัน 5 รอบวงลูป ให้นักศึกษาทำเครื่องหมายคัดเลือกเฉพาะชุดข้อมูลที่ผ่านเกณฑ์คุณภาพวิศวกรรมลงในตาราง โดยมีข้อกำหนดว่า **"ชุดข้อมูลที่น่าเชื่อถือ จะต้องมีค่า SD ต่ำสอดคล้องกันทุกเฟสสี (เช่น อยู่ในช่วง 2.00 ถึง 35.00) และต้องไม่มีค่าเฉลี่ยหรือค่า SD ใดหลุดเป็น 0.00 ในขณะที่มีการส่องสว่างส่งแสงข้ามช่องสัญญาณ"**

#### 2. คำถามเชิงวิเคราะห์ (Engineering Evaluation)

##### หลังจากเปลี่ยนสถาปัตยกรรมซอฟต์แวร์มาใช้ระบบกรองบิตดิบแบบ `Trimmed Mean` ก่อนทำการแปลงแรงดัน เปรียบเทียบกับพฤติกรรมอนุกรมเวลาในใบงานที่ 2 แล้ว ค่าความผันผวน ($SD$) มีการพัฒนาไปในทางที่ดีขึ้นอย่างไร?
**ตอบ**: 
```
จากผลการทดลองในใบงานที่ 2 พบว่าสัญญาณมีความผันผวนสูงมาก โดยมีลักษณะการแกว่งตัวแบบฟันปลา (สลับระหว่างค่า 0 และ 2500+) ส่งผลให้ค่าความเบี่ยงเบนมาตรฐาน (SD) มีค่าสูงตามไปด้วย

เมื่อปรับเปลี่ยนมาใช้สถาปัตยกรรมการกรองข้อมูลแบบ Trimmed Mean ระบบจะทำการเรียงลำดับข้อมูลและตัดข้อมูลส่วนขอบบนและขอบล่างที่มีความผิดปกติ (Outliers หรือค่าที่แกว่งไปที่ 0 และ 2500) ออกไปก่อนการหาค่าเฉลี่ย กระบวนการนี้ช่วยกำจัดสัญญาณรบกวนที่ผิดปกติได้อย่างมีประสิทธิภาพ ส่งผลให้ค่า SD ลดลงอย่างมีนัยสำคัญ สัญญาณที่ได้จึงมีความราบเรียบ เสถียรภาพสูง และมีความน่าเชื่อถือทางวิศวกรรมมากยิ่งขึ้น
```

##### ในการนำข้อมูลดิจิทัลนี้ไปใช้ควบคุมหุ่นยนต์แยกแยะวัตถุสีในโลกจริง เหตุใดการระบุหน่วยวัดร่วมประมวลผลในรูปของ **แรงดันทางกายภาพ (mV)** จึงมีความสำคัญและเสถียรมากกว่าการใช้ข้อมูลระดับบิตดิจิทัลดิบ (Raw Scale 0-4095) ตรง ๆ? ให้แปรผลโดยอิงความรู้จากเนื้อหาในหัวข้อตำราเรียนเรื่อง "สองโลกที่แตกต่าง"
**ตอบ**: 
```
อ้างอิงจากหลักการเรื่อง สองโลกที่แตกต่าง (Physical World vs. Digital World)

1.ข้อมูลระดับบิตดิบ (Raw Scale 0-4095): เป็นเพียงค่าสัมพัทธ์ในโลกดิจิทัลที่ยึดโยงกับโครงสร้างทางฮาร์ดแวร์เฉพาะตัว เช่น ค่าแรงดันอ้างอิง (V_REF) และความคลาดเคลื่อนของไมโครคอนโทรลเลอร์แต่ละตัว หากมีการเปลี่ยนบอร์ดหรือปรับค่าการทำงาน ค่าบิตดิบเหล่านี้จะเปลี่ยนแปลงไปทันที ส่งผลให้เกณฑ์การแยกแยะสีของหุ่นยนต์คลาดเคลื่อนและไม่สามารถใช้งานข้ามอุปกรณ์ได้
    
2.แรงดันทางกายภาพ (mV): เป็นหน่วยวัดมาตรฐานสากลที่สะท้อนความจริงในโลกกายภาพ การผ่านกระบวนการปรับเทียบ (Calibration) เพื่อแปลงข้อมูลดิบกลับมาเป็นแรงดันไฟฟ้า จะช่วยให้หุ่นยนต์ประมวลผลตามระดับพลังงานแสงที่สะท้อนจริง ข้อมูลที่ได้จึงมีเสถียรภาพสูง ปราศจากความคลาดเคลื่อนของฮาร์ดแวร์เฉพาะบอร์ด ทำให้ระบบทำงานได้อย่างแม่นยำและสามารถนำไปประยุกต์ใช้งานข้ามแพลตฟอร์มได้อย่างมีประสิทธิภาพ
```
